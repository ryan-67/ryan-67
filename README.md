## Projects

### nucky — LoL esports analytics platform

[![Live](https://img.shields.io/badge/live-nucky.gg-c5a059?style=for-the-badge)](https://nucky.gg)
[![Repo](https://img.shields.io/badge/repo-lol--dashboard-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ryan-67/lol-dashboard)

Production SaaS for tier-1 League of Legends esports — current-form dashboard, schedule foresight, series recaps, power ratings, and subscription **nuckyAI** analyst. Solo-built end-to-end: React/TypeScript UI, Python ETL + ML pipeline, Supabase Postgres, edge AI, and CI.

**Stack:** TypeScript · React · Vite · Tailwind · Supabase · Python · XGBoost/LightGBM

| Surface | What it does |
| --- | --- |
| **Hub & Board** | Weekly catch-up, upcoming schedule, concluded-series recaps |
| **Form** | Players, teams, and champions ranked by recent performance |
| **Predictions** | Matchup foresight from trained model artifacts |
| **nuckyAI** | Stripe-gated chat analyst grounded on warehouse stats and schedules |

**Links:** [nucky.gg](https://nucky.gg) · [lol-dashboard](https://github.com/ryan-67/lol-dashboard)
